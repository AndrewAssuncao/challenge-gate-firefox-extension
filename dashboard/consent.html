Local challenges, Python execution and grading work without AI.

If enabled, Challenge Gate sends your Anthropic API key for authentication and exercise prompts, code or command attempts, help requests, and help conversation to Anthropic over HTTPS. Git and legacy exercises may request generated challenges when opened; personalized quant explanations are requested when clicked. Anthropic receives your network address as part of the connection. Your key may incur usage charges.

Site domains, browsing URLs, time totals and the backup file are not sent by the mentor. Do not enter secrets or private information in exercises. You can turn transmission off in Settings or Firefox add-on data permissions. Declining keeps local teaching and challenges available.

Optional learning history

This separate choice adds recorded errors, completed objectives, attempt counts, performance summaries and cross-discipline progress for personalization. It is off by default. Leave it off to use AI for the current exercise (including its topic and tier) and your code, commands and chat without accumulated history or automatic error output. Declining does not disable AI.
