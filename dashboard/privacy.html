Privacy notice

Challenge Gate stores learning evidence, code drafts, legacy progress, site policies, per-domain time totals, unlocks and settings locally in browser extension storage. It has no analytics or developer telemetry. Python and local teaching use bundled code without a CDN.

Optional Anthropic mentor

AI is off until you consent. When enabled and a key is configured, generated legacy exercises and help send exercise prompts, code or command attempts, and help conversation to api.anthropic.com over HTTPS. A separate, default-off history choice adds recorded errors, objective completion, attempt counts, performance summaries and cross-discipline progress. AI works for the current exercise (including its topic and tier) without this history. Your key is sent in the authentication header. Anthropic receives your network address and handles the content under its own terms and privacy policy. Challenge Gate does not send browsing URLs, site policy lists or time totals to the mentor.

Turn AI off in Settings or revoke Firefox data permissions. Local challenges remain available. Remove the key in Settings to delete the stored credential. Requests already sent cannot be recalled.

Backups and recovery

Export is a local download initiated by you. The API-key setting, AI consent and rollback copies are excluded. Known Anthropic keys in text are redacted. Drafts, summaries, timestamps, domains and time totals may still contain personal information or other secrets you typed; inspect the file and keep it private. Anyone holding it can read it. If current data is unsupported, an explicit recovery choice saves recognized fields only, excluding unknown nested objects; download that copy for a reviewed migration. It cannot be automatically restored. Normal import never executes file contents, preserves the current key, disables AI, clears temporary unlocks, keeps the larger current or backed-up total for today’s consumed time, and saves one local rollback copy excluding the API-key setting and redacting known keys. Browser profile deletion or add-on removal may erase that copy; an external backup is needed for recovery.

Private browsing is disabled for this build. The extension intercepts normal main-frame requests to enforce the site rules you configure; those requests are not sent to the developer.
